Cross-project working rules (concise outputs, final-decision docs) live in the global profile,
`~/.claude/profile/working-style.md`, imported by `~/.claude/CLAUDE.md`. The sequential, blocking escalation rule
for phased work lives in the `orchestrate` skill (`~/.claude/skills/orchestrate/SKILL.md`, "Non-negotiables").
Don't duplicate them here.
