When creating a new role CV from an existing finished CV (e.g. Delivery Manager from the Technical Project Manager CV in `CV/shortlist-selected/`), use only data already in the base CV. Change words, angle, positioning, summary order — do not pull extra numbers/facts from `career-context-final/` or add new bullets, even if they're confirmed. Keep word swaps minimal (e.g. don't blanket-replace "stakeholder" → "client").

**Why:** User already curated the base CV to a state they're happy with; variants must stay consistent across the 4 applications.

**How to apply:** Mirror the light-touch pattern of the Program Manager CV (title swap, keyword swaps, sub-header prefix, reordered summary). Role title for that variant is "Senior Technical Delivery Manager".
